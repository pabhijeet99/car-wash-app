One-time Setup

Enter your Google OAuth Client ID to connect this app to Google Sheets. This is a free, one-time step.

📋 Step-by-step
1Go to console.cloud.google.com and create a project
2Enable Google Sheets API and Google Drive API
3Create OAuth Client ID → type: Web application
4Add your site URL to Authorized JavaScript origins
5Copy the Client ID and paste below
Looks like: 123456789-abcdef.apps.googleusercontent.com

Your Client ID is stored only on this device
